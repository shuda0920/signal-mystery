# 學習證據接收端部署

此資料夾的 Code.gs 對應使用者提供的 Game_learn 試算表。程式第一次收到有效資料時，會新增 learning_events 工作表，不修改現有工作表。

1. 開啟指定試算表，選「擴充功能 → Apps Script」，貼上 Code.gs 並儲存。
2. 在 Apps Script 選「部署 → 新增部署 → 網頁應用程式」，執行身分選自己，存取對象選「任何人」。依 Google 提示授權。
3. 複製部署後以 /exec 結尾的網頁應用程式網址（試算表網址不是接收端網址），提供給專案維護者。
4. 維護者設定遊戲端網址、測試實際送達與重送、確認試算表出現測試資料，再更新公開網站。

此端點允許匿名寫入，因此必須視為可被濫用及偽造；程式限制資料格式、欄位和大小，不保證防止惡意流量。定期檢查執行紀錄與配額。只允許事件代碼，不接受姓名、電子郵件或自由文字。測試資料應以測試用識別碼標示並於測試後清理。
